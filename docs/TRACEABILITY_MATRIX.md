# Shortify — Requirement Traceability Matrix (RTM)

**Status Legend:**
- `IMPLEMENTED` — Code or configuration exists.
- `AUTOMATED TEST PASSED` — Specified automated test executed and passed with logged evidence.
- `LOCALLY VERIFIED` — Running local behavior verified interactively or via CLI.
- `MANUALLY VERIFIED` — Human-performed verification completed with documented evidence.
- `DEPLOYED` — Release running in target environment.
- `DEPLOYMENT VERIFIED` — Post-deployment acceptance tests passed.
- `BLOCKED` — Documented dependency or limitation prevents completion.
- `NOT TESTED` — Verification has not yet occurred.
